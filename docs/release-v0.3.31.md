# 芜湖AI v0.3.31

- GeekNow 图片中转站新增 `gpt-image-2.6-sunburst`，支持文字生成、参考图输入、PNG 图片和 GIF 动图。已有 GeekNow 配置自动补入新模型，保留原有模型配置、密钥和自定义地址。
- 参数卡新增质量选择、自定义像素宽高、GIF 帧数和每帧时长。比例与清晰度档位在提交时转换成实际像素；GIF 使用自动尺寸。2K / 4K 为换算预设，实际尺寸支持以上游为准。
- 按实际文件内容验证 GIF 格式和帧间变化，识别后保留原始动图字节，避免将静态分镜图误判为动图。
- 增加桌面端结果下载通道。GIF 返回地址随项目保存，下载失败后可以继续下载已生成的结果，不重复提交生成请求。
- 合并 v0.3.30 已发布的器灵 1080P 模型更新。

使用入口：图片节点 → GeekNow → GPT Image 2.6 Sunburst；格式、质量和动画参数位于“更多参数”。

下载：安装版用于安装与升级，便携版解压/运行使用。沿用现有云端授权，保留项目、素材和中转站配置。

验证使用本地与模拟数据，未调用付费生成接口。
