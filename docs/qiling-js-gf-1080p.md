# 器灵 JS / GF 1080P

新增两个器灵模型，可在现有视频节点选择；启动时自动合并到已有器灵配置，保留密钥、默认中转站和自定义模型。

| 型号 | 协议 | 素材 | 模式 |
| --- | --- | --- | --- |
| SD2.5-满血-JS-1080P | 原视频协议，省略统一版本头；duration / ratio / resolution | 30图 / 10视频 / 10音频 | 文生、参考生成 |
| SD2.5-满血-GF-1080P | 统一视频协议，X-Qiling-API-Version: 1；seconds / aspect_ratio / resolution / mode | 10图 / 5视频 / 5音频 | 文生、参考生成、首帧、首尾帧 |

两者固定1080P，支持4–30秒整数时长。器灵当前将GF的实际生成模型标注为Wan3.0，界面显示该备注。JS目录与静态文档存在差异，画幅保守采用六种固定比例，不开放adaptive；平台对部分新增参考范围注明尚未完成渠道实测。

本地图片沿用现有器灵上传流程；参考视频和音频须提供已上传的HTTPS链接。GF的视频、音频分别合计最多15秒。首帧必须恰好1图，首尾帧恰好2图且按顺序排列，不能混入音视频。

提交和查询按模型分流协议，避免同一中转站并行使用JS/GF时串用版本头。下载优先保留返回URL及完整签名参数，第三方地址不附带器灵密钥；JS保留原接口content下载回退，GF不拼接未返回的下载地址。提交超时不自动重新POST。

源码验证覆盖请求格式、版本头、任务查询、边界限制、首尾帧、配置迁移和下载；不使用真实密钥、不提交付费生成任务。实际账户权限和成片效果仍以平台结果为准。
