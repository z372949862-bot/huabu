# 芜湖AI 一机一码：本地试用

此阶段是本机试用，未部署 Cloudflare，未推送 GitHub，未修改正式安装版。客户端为 F:/WuhuAI/license-trial-v1/芜湖AI授权试用.exe，独立用户数据位于 %APPDATA%/WuhuAI License Trial。正式版仍使用 AI Video Canvas 数据目录。

## 试用方法

1. 打开桌面「芜湖AI 授权管理试用」。管理页地址为 http://127.0.0.1:18765/admin，仅本机可访问；快捷方式同时打开管理登录码文件。
2. 在后台输入客户备注与有效天数，点击「生成一机一码」。完整激活码只显示一次，请自行保存。
3. 打开桌面「芜湖AI 授权试用版」，输入激活码，进入独立工作区。
4. 后台点「停用」后通常 15 秒内回到激活页；点「恢复」后可重新验证。续期延长授权期限；解绑使旧设备下次验证失效，允许原激活码绑定新设备。
5. 试用版离线凭证有效期 60 秒，用于快速观察服务中断的效果；正式版宽限与校验间隔上线前另定。

## 私有文件

F:/WuhuAI/license-trial-private 保存签名私钥、授权数据库和管理员登录码。不要发给客户、不要提交 Git。客户端仅含服务器公钥，不含管理后台或签名私钥。授权码在数据库中只保存摘要。

设备绑定使用 Windows 安装标识的摘要和本机生成的 Ed25519 密钥。私钥通过 Electron safeStorage 保护。重装系统或 Windows 账户改变可能需要管理员解绑；这不是 TPM 硬件证明，不能承诺绝对防破解。
