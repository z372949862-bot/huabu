# v0.3.24 云端授权与版本控制

记录日期：2026-10-30。使用所有者 Cloudflare 账号的 Workers + D1；部署、备份、恢复和日常管理详见 [license-cloud.md](license-cloud.md)。

## 发行规则

- v0.3.24 起，新用户和升级用户都必须先激活，一份码绑定一台电脑。旧项目、API Key、安装记录或配置不能代替授权。
- 主进程检查授权，限制受保护 IPC 和未授权工作区请求。已有付费任务保留恢复查询、保存及下载路径，不能借此提交新生成任务。
- 客户端只含服务地址和 Ed25519 公钥；私钥、管理员登录码、真实激活码和授权数据库不得进入仓库或发行包。
- 首次激活必须联网；每 5 分钟刷新，原凭证最多有效 1 小时且不超过授权到期时间。网络故障不误报为管理员封禁。
- 正式版沿用 `%APPDATA%/AI Video Canvas`，授权保存在独立加密文件，不删除项目、素材和中转站设置。测试版使用独立数据目录。

## 最低版本策略

后台开关默认关闭，最低版本预填 `0.3.24`。先确认新安装包已发布，再提高最低版本。v0.3.24 及后续客户端收到签名限制后锁定工作区并显示更新入口，10 秒后由主进程退出；刷新不会重置计时，已缓存的限制断网重启仍有效。收到后台新策略取消限制时撤销计时，正常授权要求仍然有效。

未收到策略的离线设备无法即时获知新限制；其原授权凭证仍按最长 1 小时到期。在线运行通常在下一次 5 分钟检查生效。相同基础版本的预览版低于稳定版。

v0.3.23 及更早的旧副本没有授权和最低版本模块，不能通过发布 GitHub 更新或云端配置追溯关闭。不得向用户宣称旧版能被远程强制停用。

## 验收与维护

自动测试覆盖设备绑定、防重放、管理员登录与 CSRF、停用、恢复、解绑、续期、离线到期、旧数据不绕过授权，以及版本签名、10 秒退出、断网重启和撤销限制。真实云端验收使用临时授权并在结束时停用；所有者已在独立桌面客户端激活进入首页。

当前电脑的网络已成功连接 workers.dev；其他目标网络仍需实际验证。正式打包检查拒绝未配置服务、HTTP、本地试用和预览配置。重部署沿用原签名密钥，迁移前备份 D1，所有者另行保管私有资料和恢复方式。
