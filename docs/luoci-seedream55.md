# 洛辞 Seedream 5.5（0.3.40）

在图片节点选择「洛辞」中转站，再选择「Seedream 5.5」。已有洛辞配置会自动补入新模型；原 Seedream 5 Pro 和自定义模型保留。

- 模型 ID：`seedream-5-5`。
- 清晰度：1K、1.5K、2K，按界面所选档位发送。
- 画幅：自动、1:1、9:16、16:9、3:4、4:3、2:3、3:2、1:2、2:1、21:9。
- 参考图：最多 10 张 PNG、JPEG 或 WebP，单张最多 30MB，保留原图字节。
- 使用洛辞 API Key 与 API 积分余额，网站会员积分不通用。

本地参考图先申请官方上传凭证，再直传文件、确认素材，将返回的 ID 放入 `referenceImageIds`。上传到存储服务时仅使用签名请求头，不携带洛辞 API Key。

生成前调用报价接口；生成使用与报价相同的参数。按用户提供的文档，基础价格分别为 0.026、0.033、0.055 API 积分，每张参考图每份输出另加 0.006 API 积分，实际按平台报价及结算为准。

提交前保存原参数与幂等键；收到任务号后立即保存。超时、重启、取消等待或下载失败后，可继续获取上次图片。已有任务只查询和下载，未取得任务号的提交复用原参数、原幂等键。清除记录前请先到洛辞核对上次任务。

本地测试覆盖模型目录、参数校验、授权上传/直传/确认、报价与生成参数一致、鉴权下载、幂等恢复、任务跨项目保存、取消与磁盘写入失败。另用一张合成测试图片验证了真实接口的申请凭证、上传及确认素材，三步均成功；未进行真实付费生成。

上传凭证的 `expiresAt` 实际为数字时间戳。软件取得凭证后立即直传，由存储服务校验有效期，避免日期格式或本机时间造成误判。只有上传成功才确认素材，失败时不会提交图片生成。
