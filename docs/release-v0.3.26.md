# 芜湖AI v0.3.26

- 修复 AIIDE 查询临时返回 HTTP 502、`fail_to_fetch_task` 或网络异常时直接停止的问题，增加有限退避重试。
- AIIDE 任务 ID 随项目保存，重启后可点击“继续查询上次任务”，使用原任务获取结果；不会自动重新提交付费生成。
- 调整 AIIDE 本地参考素材的桌面上传方式，增加有限重试、缓存和同素材并发合并，移除发给图床的中转站密钥。上传失败会在提交生成前停止。
- 修复取消查询、切换项目后晚到的提交结果，以及复制节点时的任务状态处理。

本次更新沿用云端一机一码授权，保留已有项目、素材、中转站配置和授权数据。

注意：本地素材仍需要通过图床转换为公网链接，平台或图床故障仍可能导致失败。旧版本已报错但提交状态不明的任务，请先到 AIIDE 平台核实，避免重复生成。

验证：38 个测试文件、309 项测试通过；前端构建通过。验证未调用付费生成接口。
