# DMXAPI 本地接入检查（2026-10-09）

检查范围：AI Video Canvas 的 DMXAPI Seedance 2.5 提交、引用绑定、查询、取消、项目隔离、任务恢复及播放参数。未调用付费生成接口。

## 已修复

| 问题 | 触发条件及影响 | 修复 |
| --- | --- | --- |
| 提示词引用未绑定素材序号 | 图片徽章被替换成文件名，缺少与请求素材顺序一致的模型引用 | 按连接素材、本地素材的实际顺序绑定为 @图像N / @视频N / @音频N；失效引用在提交前报错 |
| 本地素材走错上传服务 | 原代码把 DMXAPI Key 传给 imageproxy.zhongzhuan.chat | 图片改为本地读取后 Base64 直传 DMXAPI；视频/音频按现有选择使用公网链接或素材 ID，不上传到其他服务 |
| 错误识别任务及结果 | 混淆外层响应 ID、消息 ID 与任务 ID；给文本任务 ID 添加不存在的前缀；拼接多个文本块破坏内嵌 JSON | 精确识别网关任务 ID，逐块解析响应；输入素材不参与结果查找 |
| 提前显示完成或漏掉结果 | 有预分配 URL 时仍在 processing，却判成 completed；有效视频 URL 没有扩展名时无法识别 | 以任务状态为准；支持明确视频结果字段中的无扩展名链接；已完成但缺 URL 时保留任务供再次查询 |
| 取消后旧响应回写、跨项目写入 | 只清理定时器，无法拦截已发出的查询；结果使用回调时的当前项目 | 每次执行拥有独立取消信号和身份检查；切换项目时停止该项目查询；历史归属使用提交时项目 |
| 重启后任务丢失 | 持久化主动删除 taskId | 独立保存不含 API Key 的任务信息；恢复后可点击“继续查询上次任务”，不会重新提交生成 |
| 临时查询失败直接中断 | 429、5xx 响应使任务停止，用户可能重新付费提交 | 对查询做有限次数退避重试；查询失败保留任务 ID；创建请求不自动重试 |
| 编辑/延长模式及播放参数 | 默认 MOV 可能无法在内置播放器播放；重进节点时编辑模式被重置 | 默认输出 MP4，恢复保存的模式；编辑固定 adaptive / -1 |
| 非法时长和无效首尾帧选项 | 时长范围 -1～30 允许选择 0～3；首帧/首尾帧都按普通参考图提交 | 时长仅允许自动或 4～30；按实际模式发送 first_frame / last_frame，首尾帧可使用同一图片 |

原先媒体项携带不支持的 name 字段的修复保留，并补充“单个媒体项只能带对应类型内容”的回归用例。

## 仍需后续处理

1. **结果视频本地保留（已补齐）**：新生成的远程成片自动保存到应用数据目录 generated-videos/automatic，历史保留原始 URL、本地路径和保存状态。保存成功后预览使用本地文件；保存失败不改变生成成功状态，可在视频预览窗口重试。启动恢复中断的保存，不重新提交生成。旧历史可手动保存；已过期链接仍需平台提供有效地址。
2. **1080p 的播放兼容性**：DMXAPI 文档说明 1080p 使用 H.265/HEVC；部分环境无法直接预览。默认 MP4 只解决默认 MOV 的兼容性问题，不能解决全部编码兼容问题。可进一步提供兼容预览转码。
3. **“测试连接”的真实性**：当前 DMXAPI 的 testAuth 只校验 Key 格式，没有请求平台验证权限和模型可用性。现有界面成功提示不代表已经通过真实鉴权。
4. **媒体尺寸和时长预检**：数量、本地图片大小和请求体大小已限制，视频/音频总时长、远程图片尺寸仍由上游检查。可以增加本地媒体探测，减少提交后报错。

旧代码存在向非 DMXAPI 图床发送 DMXAPI Key 的路径。本轮没有查询用户历史网络请求；如以前在该路径成功发起过本地素材上传，建议在平台更换相应 Key。

## 对照文档

补充修复：通用视频轮询增加单次在途查询和运行身份检查，取消、切换项目或重新执行后忽略旧请求。成片完成即停止计时，避免旧请求超时覆盖结果或孤立定时器重复提示。下载过程与生成结果分开处理。自动下载使用临时文件、完整性检查、原子改名、两路并发和五分钟保存超时；不向成片地址附带 API 密钥。
